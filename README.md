# gofika Scoop bucket

[Scoop](https://scoop.sh) manifests for gofika tools.

```powershell
scoop bucket add gofika https://github.com/gofika/scoop-bucket
scoop install polyctl
```

| App | Description |
| --- | --- |
| [polyctl](https://github.com/gofika/polyctl) | Manage domains, DNS and cloud resources across platforms |

Manifests in `bucket/` are generated by each project's release pipeline; do not edit them by hand.
